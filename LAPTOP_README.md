# Video Pilot laptop notes

This snapshot includes the laptop/web stack for development and testing. Keep
the laptop's `.env`, cookies, database files, uploads, and personal media
outside Git. Copy an example environment file and fill it with your own local
values.

For the native iPhone host, follow [`ios/README.md`](ios/README.md). The iPhone
host and Cloudflare relay are separate from the laptop runtime; do not copy a
laptop secret into an IPA or an Actions workflow.
